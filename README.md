# Makadi Heights — Landing Page

Next.js 16.3.8 · React 19.3 · Tailwind 4 · TypeScript · Web3Forms

## قبل الرفع
عدّل `lib/site.ts`:
- `web3formsKey`
- `adsId` و `conversions` (form / whatsapp / call)
- `url` (الدومين)
- `phone` / `whatsapp` لو مختلفين
- نصوص العربي والإنجليزي وخطة السداد في `lib/content.ts`

## الروابط
- `/` عربي
- `/en` إنجليزي
- `/thank-you` و `/en/thank-you`

## تشغيل
npm install
npm run dev
npm run build
